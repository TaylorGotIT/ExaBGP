# 版本演进

## v6.4.0（2026-11-08）— IPv6 双栈与运维可见性

**定位**：把 IPv6 注入跑通并把"发了什么、发没发到"变成可查、可核对、可追溯。

### 新增
- **IPv6 路由注入**：分组/数据源支持 v6 前缀，MP-BGP 单会话承载双地址族；IPv6 下一跳输入与校验
- **发布表核对**（邻居行「核对」）：拉取 `show adj-rib out` 与分组配置比对，输出 `missing / extra` 漂移
- **下发台账**：每个 peer 记录"发过哪些数据源 / 路由组"及登记时间，落盘 `peer_ledger.json`，重启自愈
- **前缀查询支持覆盖关系**：精确命中 / 被更大前缀覆盖 / 含已发布子网（`exact / covered / contains`）
- **撤回回落语义**：撤回路由组时，仍被数据源覆盖的前缀按分组属性自动回发，并逐条打印 `♻️` 命令

### 改进
- 邻居监控：组可折叠、运行时长与报文计数（`UP / ST / RC`）、只看异常、回显可展开
- 邻居状态不再因光标在表格内而停止刷新（重绘后恢复焦点与光标）
- 前缀查询与已下发来源改用悬浮窗展示完整信息；快照过期给出明确提示
- 操作按钮精简（移除与 `adj-rib-out` 重复的 `show route` 等）

### 移除
- 内置访问令牌（`API_TOKEN` / `VIEWER_TOKEN`）及 🔑 入口：改由反向代理或网络隔离保护端口

### 文档
- 新增 [测试拓扑](test-topology.md)：一套已跑通的 v4/v6 双栈实验环境与验证用例
- `routing-attributes.md` 补充 CE 侧 v6 地址 DAD 冲突（`[DUPLICATE]`）排查

## v6.3.0（2026-11-08）— 原生安装

- **不再局限于 Docker**：`packaging/linux` 提供 install/uninstall/run/systemd 单元与打包脚本
- 一条命令装成系统服务：装依赖 → venv(exabgp+tornado) → 写 `/etc/exabgp-injector/env` → systemd
- 检测到已有 ExaBGP 进程/容器时只安装不启动，避免抢同一 BGP 会话
- `http_api.py` 路径支持环境变量覆盖：`DATA_DIR` / `RUN_DIR` / `CONFIG_FILE` / `CONF_FILE`
- 列表分页、快照面板移除、日志文案精简、下发记录并入分类日志、前缀查询并入操作行等界面调整

## v6.2.0（2026-11-08）— 运维化

**定位**：从"能注路由"变成"敢给运维用"——每一次改动都有护栏、有留痕、有预演。

### 操作安全
- **二次确认 + 影响预览**：删除/下发/撤回前展示目标分组、邻居、下一跳、属性、前缀数
- **下发预演（dry-run）**：发布前先返回将执行的命令（前 5 条 + 总条数），确认后才真正写管道
- **前缀预检**：手动粘贴/新增路由组时本地校验，区分"非法/重复/合法"，可只提交合法项
- **忙碌态与 toast**：所有按钮点击有 loading，成功/失败统一提示
- **异常横幅**：SSE 断开、数据源抓取失败、邻居未建立（含所属分组）常驻顶部

### 可追溯
- **操作审计**：所有 POST 写操作落 `audit-YYYY-MM-DD.jsonl`（时间/操作者/来源 IP/动作/目标/参数/结果），面板可查可导出 CSV
- **配置漂移检测**：「配置」弹窗对比磁盘 `exabgp.conf` 与当前渲染结果（忽略生成时间戳），差异着色

### 权限与告警
- ~~API_TOKEN / VIEWER_TOKEN~~：可选鉴权（v6 后续版本已移除，改由反向代理/网络隔离）
- **Webhook 告警**：邻居状态变化、数据源抓取失败按 key 去重推送（钉钉/企微/Slack）

### 可观测
- **`/metrics`**：Prometheus 文本格式（路由数/源/组/邻居状态/最近刷新）

### 数据源
- **可绑定分组**：`可见分组` 决定路由发往哪些组；留空=全部；删除分组前必须先解除绑定
- **解析增强**：纯 IP 自动补 `/32`、主机位归一、支持 `;` 行内注释（Spamhaus DROP 格式）
- **默认频率 1 小时**，未绑定源不再串流到专用组

### 体验
- 深色/浅色主题切换（记忆选择，首屏不闪）
- 表格列宽百分比化，名称/URL 不再随窗口忽大忽小
- 分组选择改为复选框下拉；分组增删后选项即时同步；失效绑定标琥珀色
- 路由组前缀分页（默认 200 条，可加载更多）

### 修复
- 多个分组指向同一邻居时 `exabgp.conf` 出现重复 `neighbor` 导致容器起不来（按 IP 去重）
- 开机回填用全库并集发给所有组，会把黑洞属性路由灌进普通组（改为按组可见并集）
- 配置漂移误报（生成时间戳参与比较）

## v6（当前主线）

**定位**：从"单脚本注路由"变成"可运维的路由注入平台"。

新增/定型的能力：

- **多数据源**：每源独立 URL、频率、启停；各自维护集合与磁盘快照，重启自愈。
- **分组邻居传播**：一个分组 = 邻居列表 + 下一跳 + 属性，支持逐组覆盖 `local-as / peer-as / local-address / router-id`。
- **IP 路由组**：手工粘贴或 URL 导入前缀集合，勾选批量发布/撤回，可整体覆盖下一跳与属性。
- **`exabgp.conf` 自动生成**：`confgen.py` 按分组模板渲染，改分组自动重生成并热重载（不重启容器）。
- **可视化控制台**：邻居状态、命令回显、实时日志（SSE）、数据源/路由组/分组在线管理、手动发布。
- **选路属性**：`community`、`MED`、`AS-PATH prepend`，按分组或路由组配置；属性变更自动重播全库。
- **可观测性**：按前缀查询是否已发布、运行时参数快照、按天滚动日志（大小/留存可配）。
- **表格化界面**：所有管理面板统一为固定列宽表格（表头 / 数据行 / 新增行三行对齐），KPI 卡片、双栏布局、响应式。
- **工程化**：容器时区固定 `Asia/Shanghai`、控制台禁用浏览器缓存、`--restart` 策略、镜像多阶段可回滚。

## v5 及更早（演进原型）

早期版本用于验证"ExaBGP 注路由"这条路是否可行，能力逐版叠加：

| 版本 | 关键变化 |
|---|---|
| v1 | 手工维护 `exabgp.conf` + FIFO 注入，验证 BGP 会话与宣告 |
| v2 | 容器化：Dockerfile 打包 exabgp，挂载配置与管道 |
| v3 | 引入 `http_api.py`，用 HTTP 触发批量下发/撤回 |
| v4 | 抽出"邻居 / 下一跳 / community"参数，支持多邻居 |
| v5 | 单一数据源（中国 IP 段）+ 定时刷新 + 简易控制台 |

> v1~v5 只作为演进记录，未随仓库发布。
